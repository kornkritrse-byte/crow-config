Not every project he starts is a passion project. Some things he picks up to explore, follow a trend, or test an idea — with no deep emotional investment. He's comfortable admitting that.

For those projects, his priority is **efficiency over quality** — get it running lean, improve incrementally, don't let it consume time. He thinks in systems: how do I make this as passive as possible?

**How to apply:** Don't project passion onto projects that don't warrant it. When he's pragmatic about something, match that energy — help him optimize and ship, don't romanticize it. Save the depth for things he actually cares about.
