# Crow on ChatGPT
A ChatGPT **project** for Korn: voice book-talk on Zone 2 runs, Samneang images, and talk on the go. Replaces the claude.ai "Zone 2 Book Runs" project (`briefs/zone2-book-runs.md`, now retired).

## Set it up (once)
1. ChatGPT → Projects → New project → name it **Crow**.
2. Project settings → **Instructions**: paste all of `instructions.md`.
3. Project **files**: upload `../CROW.md`, `../briefs/korn-reader.md`, `samneang.md`.
4. Optional: connect Notion in ChatGPT (Settings → Connectors) so it can read Brand HQ. Use HIS own account; it must log as "ChatGPT (for Korn)", separate from Patrick's.
5. Memory: set the project to project-only memory if offered, so it doesn't mix with his other chats.

## Keep it fresh (Crow's job)
- Book or reading thread moves on → update the "Mode 1" book line in `instructions.md` + `briefs/korn-reader.md`, tell Korn to re-paste / re-upload.
- Brand decision changes (product, logo, direction) → update `samneang.md`, tell Korn to re-upload it.
- Each file says the date it was written. Stale = older than the last big change.

## Coming back
ChatGPT ends each chat with a **"For Crow:"** summary. Korn pastes it into the Crow Room; Crow files it into memory (and the said/did ledger if there's an "I'll do X").
